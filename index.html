Par où commencer

  1. Lire le cours et les méthodes (formules, conversions, erreurs fréquentes).
  2. Refaire l'exercice avant d'ouvrir la correction.
  3. Comparer, puis lire la correction : chaque étape est expliquée, avec le pourquoi.
  4. S'entraîner avec le QCM autant de fois qu'on veut : les questions et les réponses changent à chaque série.

Les 3 réflexes à garder

Convertir avant de calculer mL → L (÷ 1000), mg → g (÷ 1000), mS·cm⁻¹ → mS·m⁻¹ (× 100).
À l'équivalence, les quantités sont dans les proportions de l'équation Pour Ba²⁺ + SO₄²⁻ → BaSO₄, a = b = 1 : n(Ba²⁺) versé = n(SO₄²⁻) présent.
Une réponse « justifier » contient toujours un chiffre Valeur mesurée, valeur de référence, écart, conclusion.
